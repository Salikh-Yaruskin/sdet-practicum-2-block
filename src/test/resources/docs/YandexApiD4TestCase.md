# Задача D4. Тестирование API

## План тестирования

- **Объект тестирования:** Yandex Disc API, создание, удаление, восстановление директорий, создание текстового файла
- **Цель:** Протестировать корректность работы API
- **Инструменты:** Fiddler, Postman, RestAssured

## Критерии начала тестирования

1. Описаны тест кейсы, которые будем тестировать
2. Есть доступ к API Яндекс диска (валидный токен)
3. Определены и доступны инструменты

## Критерии окончания тестирования

1. Выполнены и автоматизированы все тест-кейсы из списка
2. Найденные дефекты заведены в баг-трекер

## Тест-кейсы

| ID   | Наименование                   | Предусловия                                            | Входные данные                                                  | Ожидаемый результат                                                         |
|------|--------------------------------|--------------------------------------------------------|-----------------------------------------------------------------|-----------------------------------------------------------------------------|
| F-01 | Создать простую папку          | Валидный токен                                         | `PUT /v1/disk/resources?path=/demo/folderA`                     | Директория создана; код `200 Created`; Директория видна в списке директорий |
| F-02 | Создать уже существующую папку | Валидный токен, папка `/demo/folderA `уже существует   | `PUT /v1/disk/resources?path=/demo/folderA`                     | Возврат ошибки конфликта `405`, папка не дублируется                        |
| F-03 | Создание без авторизации       | -                                                      | `PUT /v1/disk/resources?path=/demo/folderB`                     | `401 Unauthorized`                                                          |
| F-04 | Удалить папку в корзину        | Валидный токен, существует /demo/folderA               | `DELETE /v1/disk/resources?path=/demo/folderA`                  | `200 Accepted`; ресурс перемещён корзину                                    |
| F-05 | Удалить папку без корзины      | Валидный токен, существует /demo/folderA               | `DELETE /v1/disk/resources?path=/demo/folderA&permanently=true` | `204 No Content;` в корзине отсутствует                                     |
| F-06 | Удаление несуществующей папки  | Валидный токен, директория /demo/folderC не существует | `DELETE /v1/disk/resources?path=/demo/folderC  `                | `404 Not Found`                                                             |
| F-07 | Восстановить папку из корзины  | Валидный токен                                         | `PUT /v1/disk/trash/resources/restore?path=`                    | `200 OK`; папка восстановлена в исходный путь; из корзины исчезла           |
