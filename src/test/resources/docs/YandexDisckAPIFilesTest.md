# Задача D7. JSON Schema Validation

## План тестирования

- **Объект тестирования:** Yandex Disc API получение всех файлов и проверка на соответствие ответа с его описанной
  структурой с помощью JSON Schema
- **Цель:** Протестировать корректность работы API и валидность ответа
- **Инструменты:** Postman, RestAssured, JSON Schema

## Критерии начала тестирования

1. Описаны тест кейсы, которые будем тестировать
2. Есть доступ к API Яндекс диска (валидный токен)
3. Определены и доступны инструменты

## Критерии окончания тестирования

1. Выполнены и автоматизированы все тест-кейсы из списка
2. Найденные дефекты заведены в баг-трекер

## Тест-кейсы

| ID   | Наименование            | Предусловия                         | Входные данные                 | Ожидаемый результат                                |
|------|-------------------------|-------------------------------------|--------------------------------|----------------------------------------------------|
| F-01 | Получение списка файлов | Валидный токен, на диске есть файлы | `GET /v1/disk/resources/files` | Код ответа `200 OK`; тело JSON соответствует схеме |
