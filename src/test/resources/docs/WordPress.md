# WordPress

## План тестирования
- **Объект тестирования**: REST API WordPress (CRUD операции постов, категорий, комментариев) с проверкой изменений в БД
- **Цель**: Протестировать корректность работы REST API
- **Инструменты**: Postman, MySQL client/JDBC, docker

## Критерии начала тестирования
1. Поднято и настроено окружение: WordPress И MySQL, `GET /wp-json/wp/v2/users/me` отвечает 200 с JSON
2. Есть пользователь с правами на создания/редактирования/удаления постов и управления терминами
3. Доступ к БД настроен
4. Определены и доступны инструменты

## Критерии окончания тестирования
1. Выполнены все тест-кейсы из списка
2. Для каждого кейса зафиксированы фактические результаты HTTP и SQL-проверок
3. Найденные дефекты заведены в баг-трекер
